# Figure captions

Generated by `uv run main.py plots` from the files in `logs/`.

**fig1_learning_curves.png**: Learning curves of the four algorithms (Phase 2: picked config, 5 seeds, 600k frames). Line: mean across seeds; band: min-max across seeds. (a) Evaluation return on the 10 validation seeds in each agent's eval mode (DQN greedy, policy-gradient agents sampled). (b) Return of training episodes, averaged per 10k-frame bin (includes DQN's epsilon exploration).

**fig2_dqn_objective.png**: DQN objective (dqn_c08, 5 seeds). Line: mean across seeds; band: min-max. (a) TD loss per gradient step, averaged per 10k-frame bin. (b) Mean Q-value predicted for the sampled replay batches. The dotted line marks the first gradient update (learning_starts).

**fig3_pg_entropy.png**: Entropy of the masked action distribution for the policy-gradient agents (Phase 2, 5 seeds), averaged per 10k-frame bin. Line: mean across seeds; band: min-max. The dotted line is the entropy of a uniform policy over all 17 actions; with masking the real maximum is lower.

**fig4_convergence.png**: Convergence and stability (Phase 2, 5 seeds per algorithm). (a, b) First evaluation at which a run's validation return reaches 40 and 50; one dot per seed, hollow dots at the right edge never reached it. (c) Standard deviation of the validation return across seeds over training (5-evaluation rolling mean): lower means more stable across seeds.

**fig5_generalization.png**: Held-out evaluation: mean return on the 50 test seeds (never used for training or model selection) in the training scenario and three stress scenarios the agents never saw. Grey bars: baselines; coloured bars: RL agents pooled over 5 seeds x 50 episodes. Whiskers: 95% bootstrap CI; black dots: per-seed means.

**fig6_kpi_breakdown.png**: Why the RL agents trail the heuristics (base scenario, 50 held-out seeds, 95% bootstrap CIs). They collect as much or more waste (a) but let bins overflow longer (b) and end the shift with trucks away from the depot or still loaded (c).

**fig7_phase1_configs.png**: Phase 1 sweep: validation-return curves of all 10 configs per algorithm (seed 0, 200k frames). Dashed: base config c00; grey: the nine one-factor variants; coloured: the config picked for Phase 2 (by re-scoring on 50 separate selection seeds, see the hyperparameter tables).

**fig8_sensitivity.png**: Hyperparameter sensitivity: each Phase 1 config re-scored on 50 selection seeds (30000-30049, disjoint from training, validation and test seeds). Coloured: picked for Phase 2; dashed line: base config c00; whiskers: 95% bootstrap CI.
